  BookMyShow – Online Movie Ticket Booking System
Technologies: Java, JavaMail API, JDBC, MySQL, Razorpay API (or any Payment Gateway), Java Swing/JavaFX

Developed a Java-based movie ticket booking application inspired by BookMyShow, enabling users to browse movies, select showtimes, and book seats.

Implemented user registration and login system with email verification using the JavaMail API to enhance user account security.

Designed a secure authentication system with password hashing and session management.

Integrated Razorpay Payment Gateway API for seamless and secure ticket payments.

Used MySQL with JDBC for storing and managing user, movie, theater, and booking data.

Built an interactive and responsive GUI using Java Swing/JavaFX for enhanced user experience.

Enabled features like show search, seat selection, booking history, and digital ticket generation.
